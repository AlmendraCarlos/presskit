# ALMENDR4C4RLOS — Press Kit (React + Vite SPA)

Sitio estático, sin SSR. Español por defecto con switcher ES/EN.

## Uso
```bash
npm install
npm run dev      # desarrollo
npm run build    # genera /dist
npm run preview
```

## Deploy
- **Vercel / Netlify**: build `npm run build`, carpeta de salida `dist` (configs incluidas).
- **GitHub Pages**: subir el contenido de `dist` (el `base: "./"` ya permite subcarpetas).

Fotos y archivos descargables en `public/media` y `public/press`.
